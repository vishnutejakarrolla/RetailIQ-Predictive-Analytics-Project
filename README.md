# RetailIQ Predictive Analytics Project

1. Install packages: `python -m pip install -r requirements.txt`
2. Start Jupyter: `jupyter notebook`
3. Open `RetailIQ_Predictive_Analytics.ipynb`.
4. Update `EXCEL_FILE` in the first code cell to your actual `Online Retail.xlsx` path.
5. Select Kernel > Restart Kernel and Run All Cells.

The notebook expects the UCI Online Retail Excel dataset with columns such as InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID and Country.
